# Home

## Objetivo
La Home debe comunicar inmediatamente qué es Indie Now y destacar el contenido más importante.

## Estructura
1. Header
2. Hero
3. Últimas Noticias
4. Live Session destacada
5. Videos
6. Playlists
7. Merch
8. Footer

## Reglas
- Hero ocupa el primer viewport.
- Solo una Live Session destacada.
- Máximo 4 noticias.
- Máximo 6 videos.
- Máximo 4 playlists.
- Lazy loading para imágenes y videos.
- SEO optimizado.
